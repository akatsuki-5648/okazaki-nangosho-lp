## 🔎 極秘徹底調査（2026-07-04 パパ命令「深度10倍・1cmずれも許さない」による8カテゴリ距離マトリクス）

> パパの指示「他のいろんな町のどこまでの距離ってあるだろ、それが正確な1cmずれは許さない、深度10倍の調査を多面的に」を受け、Workflowで8カテゴリを並列徹底調査した。結論から言う——**「1cmずれない絶対座標」は物理的に存在しない。** これは手抜きではなく、調査そのものが暴いた構造的事実。理由は次項。

### ⚠️ 座標精度についての重要な発見（誠実に報告すべき事実）

複数の地図サービス・国土地理院APIで同一物件「岡崎南御所町35番9号」の座標を独立に取得し、クロスチェックした結果：

| ソース | 緯度・経度 | 何を指しているか |
|---|---|---|
| **国土地理院（GSI）公式API** | 35.014393, 135.785355 | 「岡崎南御所町**35番地**」の代表点（35番9号の枝番までは一致していない） |
| **Google Maps** | 35.0148068, 135.7852899 | 具体的建物「ル・フジタ」にヒット（個別建物レベルの解決） |
| **MapFan** | 35.0147279, 135.7852537 | Googleのクラスタ半径10m圏内 |
| **Yahoo!地図** | 35.01474, 135.78494 | 経度が他3系統から系統的に西へずれる（独自アルゴリズムの丸め誤差） |

**GSI座標とGoogle Maps座標の差は約90m。** これは誤差ではなく、「町丁目・番地の代表点」と「個別建物の位置」という**別の対象を指している**ことに起因する構造的な差。国土地理院の応答は「35番地」までしか特定しておらず、「35番9号」という枝番の精度を保証しない。距離計算の基準点には、個別建物にヒットしているGoogle Maps座標（35.0148068, 135.7852899）を採用した。**「1cmずれない絶対座標」を求めること自体が、地番と町丁目という異なる粒度のデータを混同するリスクを持つ——この事実自体を発見として報告する。**

### 南禅寺界隈別荘群との関係（2026-07-04 史実検証済み）

この物件は、明治〜昭和初期に政財界の巨頭が別荘を構えた「南禅寺界隈別荘群」（Wikipedia項目として実在）に近接する。ただし**この呼称は文化財の一括指定制度ではなく、個々の庭園が国の名勝・重要文化財として個別指定された集合体**である点は正確に理解しておく必要がある（未確認だった一括指定制度は、今回の調査でも確認できなかった＝存在しない可能性が高い）。

確認できた代表例：
- **無鄰菴**：山縣有朋が1894〜96年造営、庭園は七代目小川治兵衛作。1951年6月9日、国の名勝指定。1903年「無鄰菴会議」（山縣・伊藤博文・桂太郎・小村寿太郎）の舞台にもなった政治史料としての価値も持つ（[無鄰菴公式](https://murin-an.jp/about/)、[京都市公式](https://www2.city.kyoto.lg.jp/bunshi/bunka/murin_an/about/index.html)）

**⚠️重要な訂正（現在の所有者について）**: 南禅寺界隈別荘群の主要な現在所有者を調べたところ、碧雲荘＝野村ホールディングス、對龍山荘＝ニトリホールディングス、真々庵＝パナソニックと、**主に日本の財閥・大企業が保有しており「海外投資家中心」ではない**。海外実例として、ラリー・エリソン氏（オラクル共同創業者）が南禅寺境内にある歴史的な日本庭園付き別荘を所有していると複数の独立した海外メディアが報じている（[South China Morning Post](https://www.scmp.com/magazines/style/entertainment/article/3243504/oracle-co-founder-larry-ellisons-billion-dollar-property-portfolio-villa-kyoto-and-japanese-inspired)、[Yahoo News経由Robb Report記事](https://www.yahoo.com/news/oracle-billionaire-larry-ellisons-incredible-132632387.html)）。柳井正氏（ファーストリテイリング会長）も2020年に「洛翠」を取得（[マネーポストWEB](https://www.moneypost.jp/1169506)）。

### 軸②：岡崎南御所町・南禅寺の歴史深掘り

**町名の成立（Wikipedia原文＝wikitextで確認済み）**：岡崎南御所町の前身は愛宕郡岡崎村。明治21年（1888年）上京区岡崎町→明治22年京都市上京区岡崎町→**大正7年（1918年）に岡崎町を廃止し「岡崎」を冠する13町へ再編、岡崎南御所町・岡崎北御所町はこの時に成立**。

**「南御所」の由来（強い状況証拠、ただし公式文書は未発見）**：京都市公式「いしぶみデータベース」に、平安時代後期に白河上皇・鳥羽上皇の院御所として「白河北殿」（北新御所）と「白河南殿」（**南本御所**とも称された、聖護院蓮華蔵町）が営まれていた記録がある。「南御所町」「北御所町」という対の町名はこの記憶に由来すると考えるのが自然だが、**京都市自身がそう明記した町名由来の一次文書は本調査では発見できなかった**（強い状況証拠に基づく推定として扱う）。

**南禅寺創建史（要検証点あり）**：正応4年（1291年）、亀山法皇が離宮「禅林寺殿」を寺に改めたのが起源。**ただし離宮を最初に造営したのが「亀山天皇」か「後嵯峨院（父）」かで南禅寺公式サイトとWikipediaの記述が食い違っている**（亀山天皇は文永元年/1264年時点でまだ15歳で院政開始前のため、後嵯峨院造営説の方が年齢的には整合的だが、南禅寺自身は亀山天皇造営説を採る）。断定を避け両論併記とする。

**明治期京都復興事業の政治的背景**：東京奠都で人口が3分の2に減少した京都を立て直すため、①琵琶湖疏水（京都府知事・北垣国道が立案、総額125万円＝当時の京都府予算2年分、蹴上発電所は**日本初の営業用水力発電所**）、②第4回内国勧業博覧会（**大阪市と競願の末に京都市が誘致を勝ち取った**、当初は千本丸太町に予定も用地買収失敗で岡崎に変更）、③平安神宮創建（1895年、桓武天皇を祭神に創祀、社殿は大内裏朝堂院の8分の5規模で復元）が一体の政策として進められた。1938年昭和天皇の命令で孝明天皇が祭神に追加合祀（1940年）。

### 軸③：経済・不動産市場の深掘り

**地価上昇の実態**：2026年京都府公示地価平均36万0573円/㎡（前年比+3.92%）。京都市住宅地平均変動率+3.6%（東山区+7.1%が区別最高）、商業地+10.2%。ただしバブル期（1992年）京都府住宅地平均は285,500円/㎡で、2026年の164,100円/㎡はこれを下回る＝「バブル期並みの高騰」は平均値で見る限り誇張の可能性。

**外資系高級ホテルの京都進出（2026年、一次報道で確認済み）**：帝国ホテル京都（2026年3月開業・スイート1泊300万円との報道）、カペラ京都（シンガポール系・2026年3月予約開始）。

**民泊規制の急速な強化**：京都市は住居専用地域で年間60日のみ営業可能という独自条例を既に施行済みだが、**2026年1月29日、松井孝治市長が「もう一歩先に踏み込む」と条例改正方針を表明**。2025年4〜12月の住民通報件数は264件で2024年度通年244件を既に上回っている。

**風致地区の資産性——希少性と流動性低下の二面性**：不動産コンサルタントの実務解説記事によれば、風致地区指定は建築可能面積を約2割減らし、購買層を限定して流動性を下げる一方、**「景観重要建造物」「歴史的風致形成建造物」の行政指定を受けた家屋・敷地は相続税評価で30%の評価減**が国税庁の質疑応答事例で明確化されている（ただしこれは風致地区内の土地全般に自動適用されるものではなく、別制度である点に注意）。

**超富裕層市場での「京都ブランド」**：海外投資家（アリババ・レノボ幹部層等）による京都不動産取得は約5年前から増加し、別荘用途が約3割（京都新聞取材）。健美家/H2Group発表記事では「海外超富裕層の投資対象がニセコから東京・京都へシフト」という論調があるが、**これは業界プレスリリース由来であり第三者検証はできていない**。Knight Frank「The Wealth Report 2026」など国際的シンクタンクのグローバル高級住宅指数には**京都固有のデータは確認できなかった**（東京は+58.5%の伸びで言及あり）。

*出典：[民泊規制強化・日経](https://www.nikkei.com/article/DGXZQOUF2959E0Z20C26A1000000/) / [京都新聞・海外富裕層](https://www.kyoto-np.co.jp/articles/-/816843) / [国税庁相続税評価減](https://www.city.kyoto.lg.jp/tokei/page/0000281303.html) / [Knight Frank](https://www.knightfrank.com/research/reports/wealthreport)*

### 軸④：防災・環境リスクの深掘り

**地震リスク（最も重要な弱点）**：花折断層帯地震（M7.5、断層長約47km）では**左京区が京都市内で最大級の被害想定区域**とされ、震度6強〜7、京都府内で死者約4,700人・全壊半壊建物約258,000棟という被害想定が令和6年4月に京都府から公表されている。30年以内の発生確率は0〜0.6%。東山山麓・鴨川扇状地は盆地内では比較的安定した地盤とされる（液状化リスクが高いのは主に盆地南部の巨椋池周辺）。

**土砂災害リスク**：京都市域の7割超が山地。東山区は8地区65箇所が土砂災害警戒区域等に指定され、疏水が通る粟田地区（岡崎・蹴上・南禅寺周辺）にも5箇所の指定がある。

**水害リスク**：鴨川・高野川は洪水予報河川に指定。**琵琶湖疏水そのものの越水・浸水想定図は今回発見できず未確認**（疏水事務所への直接照会が必要）。歴史的事実として明治29年（1896年）琵琶湖大洪水時、京都市が疏水閘門を閉鎖し滋賀県側の水位がさらに上昇して対立した記録がある。

**気候変動**：猛暑日は過去50年で5.5日増加、2024年は年54日で観測史上最多。21世紀末には現状比約50日増（年65日程度）という予測が気象台資料にあるが、**この数値は間接確認でPDF原本の直接抽出には失敗**しており精度を求めるなら再確認が必要。

*出典：[京都府地震被害想定](https://www.pref.kyoto.jp/kikikanri/1219912434674.html) / [土砂災害警戒区域・東山区](https://www.pref.kyoto.jp/dosyashitei/higashiyamaku.html) / [京都気候変動適応センター](https://kccac.jp/research-report/hotdays001/)*

### 軸⑤：地域コミュニティ・京都不動産文化の深掘り

**岡崎エリア在住者の一次証言**：建築士・花本晋氏「チャレンジを受け入れる素地があるまち」、フリーライター・堀香織氏（在住2年）「一度懐に入れた人には皆さん親身、2年で鎌倉の5倍の友人ができた」。ただし**これらの証言は地元不動産会社（八清）が制作に関わるメディア掲載であり、ポジティブ証言への選定バイアスの可能性は否定できない**。

**「京都の壁」「一見さんお断り」言説の実態**：「一見さんお断り」は本来**祇園等の花街のお茶屋文化に由来する慣習であり、不動産取引に直接適用される慣習として語られている一次情報は見つからなかった**。舞鶴市の移住トラブル事例（Oricon記事で報道）は京都府北部の別地域の話であり、京都市内・岡崎エリアの話と混同されやすいが明確に区別すべき。「町内会未加入でゴミを出させない」問題は、つくば市・兵庫・埼玉・静岡・福井でも報告されている**全国的な現象であり京都特有ではない**ことが客観報道で確認できた。

**洛中・洛外という京都市内部の出身地差（確認された社会現象）**：井上章一氏（国際日本文化研究センター副所長）著『京都ぎらい』が「洛中出身者が洛外出身者を京都人と見なさない」内部序列意識を指摘。これは**不動産取引そのものではなく京都社会に根強い出自意識**として位置づけられる。地元不動産会社×京都移住計画のオンラインイベントでは登壇者全員が「いけずな京都人に会ったことがない」と証言する一方（ポジショントークの可能性はある）、匿名掲示板レベルでは否定的な体験談も存在する（検証可能性は低い）。

**総合評価**：「京都は不動産取引でよそ者を露骨に排除する」という直接的な一次証言・報道は見つからなかった。京都不動産取引の「複雑さ」の実質は、排他的な人間関係というより**新景観政策・埋蔵文化財包蔵地（京都府内約18,000箇所指定）・洛中/洛外という歴史的地理的要因に起因する制度的複雑さ**である可能性が強く示唆される。

*出典：[potel.jp岡崎記事](https://www.potel.jp/kyoto/cityguide/feature/hachise_okazaki/) / [京都ぎらい・文春オンライン](https://bunshun.jp/articles/-/6688) / [ゴミ捨て場問題は全国的・福井新聞](https://www.fukuishimbun.co.jp/articles/-/2122071)*
