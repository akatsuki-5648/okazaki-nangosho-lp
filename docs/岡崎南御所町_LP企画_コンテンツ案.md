## 🌍 ①臨場感レイヤー：Google Earth Studio 具体的な作り方

1. Chrome + Googleアカウントで `https://earth.google.com/studio/` にアクセス
2. 検索バーに「京都市左京区岡崎南御所町」または座標（35.0152, 135.7855）を入力
3. 高高度からの俯瞰カット→徐々にズームインして物件位置（公図で確認済みの赤枠区画）に寄っていくカメラワークをキーフレームで設定
   - キーフレーム1：京都盆地全体を上空から（東山・琵琶湖疏水が見える高度）
   - キーフレーム2：平安神宮・岡崎公園エリアにズーム
   - キーフレーム3：物件所在地の区画にピンポイントでズームイン
4. テンプレート（既存5種類から選択可）を使えばアニメーション知識なしでもカメラワークが組める
5. レンダリング→zip画像出力→動画編集ソフト（無料のCapCut等）で1本の動画に結合

**この動画をLPのファーストビューに埋め込むことで「臨場感アップ」を実現**（パパの指示のコア案）。
